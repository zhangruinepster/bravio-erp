# 02 - Odoo 交互风格 UI/UX 组件详细规范 (Odoo UX Specification)

---

## 1. 交互理念与视觉哲学

Odoo 之所以成为全球公认操作效率极高的 ERP，其精髓在于**高度统一、高复用、认知负荷极低**的操作范式。  
Bravio ERP 100% 借鉴其交互习惯，但基于现代响应式 Web 标准重新设计组件库，彻底摒弃旧版笨重体验。

### 视觉特征基调
- **设计风格**：现代企业级轻质极简风格（Clean Enterprise），主色调采用典雅克制的高级深青蓝/石墨灰，辅以合规安全绿与预警琥珀黄。
- **排版质感**：纸张拟真卡片（Paper Sheet）底衬，精致微阴影（Subtle Shadow），清晰的视觉层次阶梯。
- **响应式断点**：宽屏下表单与 Chatter 采用黄金比例左右分栏；中窄屏下 Chatter 自动沉底。

## 3. 六大核心 Odoo 风格组件详细逻辑

### 3.1 顶部应用切换器 (App Switcher)
- **触发机制**：点击顶部最左侧 9 点九宫格图标。
- **展示形态**：全屏毛玻璃或居中优雅浮层，展示系统内所有已启用的业务模块图标（如：人事、系统安全、KBA质量追溯、灾备控制台）。
- **键盘盲操**：唤出后支持直接打字实时模糊搜索模块名称，回车即可瞬间跳转。

### 3.2 统一控制台 (Control Panel)
Control Panel 是整个 ERP 的大脑枢纽，任何业务对象列表页与表单页均共用此模式：
1. **智能搜索与徽章胶囊（Search Badges）**：
   - 用户输入关键词时，下拉提示：`在 "姓名" 中搜索`、`在 "工号" 中搜索`、`在 "证书编号" 中搜索`。
   - 确认后自动收录为胶囊标签（Pill Tag），可单键一键删除。
2. **多维过滤器 (Filters)**：
   - 提供预置快捷条件（如：`在职员工`、`KBA资质30天内到期`、`待审批`）。
   - 支持自定义复杂逻辑（如：`创建时间 > 本月` AND `部门 == 质检部`）。
3. **动态分组聚合 (Group By)**：
   - 支持按特定维度折叠查看（如：按 `部门` 分组、按 `资质等级` 分组）。
   - 支持多级嵌套分组（如：先按 `部门` 分组，展开后再按 `岗位级别` 分组）。
4. **个性化收藏夹 (Favorites)**：
   - 允许员工将当前组合的搜索、过滤、分组保存为快捷视图，并可勾选“设为我的默认视图”或“与团队共享”。
5. **多视图切换器 (View Switcher)**：
   - 位于右上角，提供：`List (列表)`、`Form (表单详情)`、`Kanban (看板)`、`Calendar (日历/到期日程)` 视图一键无损切换。

### 3.3 列表视图 (List / Tree View)
- 支持表头多选复选框（批量操作：导出 Excel、批量归档、批量变更权限）。
- 表头点击正倒序排序。
- 支持列宽自由拖拽与自定义列显隐。
- 点击任意数据行直接滑入该条目的表单详情页，支持键盘 `↑` `↓` 键快速切换行。

### 3.4 表单视图 (Form View)
表单视图用于高价值单据/档案的查看与编辑：
1. **状态流转条 (Status Pipeline)**：
   - 位于表单正顶端，展示单据当前生命周期阶段（例如：`草稿 -> 部门审核 -> 质保部审核 -> 生效归档`）。
   - 左侧配有显眼的触发动作按钮（如 `[ 批准 ]`、`[ 驳回 ]`、`[ 打印资质证明 ]`），且动作按钮根据权限与当前状态动态显隐。
2. **快捷统计按钮区 (Smart Buttons)**：
   - 位于表单右上角，以徽章数字形式统计关联数据。
   - 例如查看某个员工表单时，右上角智能按钮展示：`[ 🪪 4 项证书 ]`、`[ 📋 12 条审计流水 ]`、`[ 🔐 2FA 已开启 ]`。点击直接联动过滤对应的子表。
3. **标签页笔记本 (Notebook & Tabs)**：
   - 采用标签页结构清晰划分：`基础档案`、`ISO/KBA 能力与培训`、`安全访问与角色`、`历史变更`。

### 3.5 核心跟踪与审计侧边栏 (Chatter Component)
**Chatter 是满足 ISO 9001 与 KBA 审查的最强利器**，它不仅是沟通工具，更是法律级审计事实记录仪：
1. **操作操作区 (Action Bar)**：
   - **`发送消息 (Send Message)`**：向相关协同人发送通知。
   - **`记录内部备注 (Log Note)`**：仅内部可见的说明（如：“2026-10-17 审核员现场核验原件无误”）。
   - **`安排活动 (Schedule Activity)`**：设定日程待办（如：“2027-01-10 需进行 KBA 年审复核”），自带红/黄/绿超期预警灯。
2. **不可伪造的审计轨迹流 (Audit Trail Stream)**：
   - 后端数据库变动自动推送至 Chatter 时间轴。
   - 清晰渲染：`[修改时间]` `[操作人头像及姓名]` `修改了字段 [岗位]：由 "质检助理" 变更为 "质量工程师 (KBA专项)"`。
   - 任何人工都无法在前端修改或删除已生成的审计流水。

### 3.6 看板视图 (Kanban View)
- 适合可视化流程推进（如员工资质年审状态推进、部门组织卡片、岗位聘任看板）。
- 支持卡片拖拽触发后端状态流转与权限二次核对。
